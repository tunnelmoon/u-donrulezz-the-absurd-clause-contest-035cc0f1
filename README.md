# The Absurd Clause Contest

make.fun bounty entry. The program writes one line, an absurd clause hidden
deep inside a terms-of-service agreement, to `entry.txt`.

> Clause 17.8: all disputes arising under these terms shall be settled by a
> dance-off judged by the Company's intern, whose decision is final and
> non-appealable.

Run with Node 22: `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`. The output is
a single line of 159 characters, inside the 200 character gate.
